Description

Cuote Generator is a beautifully designed and fully responsive web application that generates random quotes fetched from the Quotable API. Users can generate a new quote with a single click or copy the current quote to their clipboard. The design is clean, modern, and adapts seamlessly to any device, providing an excellent user experience.

Features ✨

Random Quote Generation: Fetches a new random quote with tags from the Quotable API.
Copy to Clipboard: Easily copy the generated quote to your clipboard.
Responsive Design: Works perfectly on desktops, tablets, and mobile devices.
Minimalist and Modern UI: A clean and visually appealing interface.
Tags Display: Shows relevant tags for each quote.
Technologies Used 🛠️

Frontend: HTML5, CSS3, JavaScript
API Integration: Quotable API
Design: Flexbox, CSS Grid, and Media Queries for responsiveness
Icons: Font Awesome
How to Use 🚀

Open the web application in your browser.
A random quote with its tags will be displayed automatically.
Click the "New Quote" button to generate a new random quote.
Click the "Copy to Clipboard" button to copy the current quote to your clipboard.
